# PPT 图片互转工具 v3.3（缩略预览与大图查看版）

面向 Windows 日常办公、电商设计和批量素材处理的桌面转换工具，提供两项核心能力：

1. **PowerPoint 批量导出 PNG / JPG**
2. **多张图片按顺序合成为 PPTX，每张图片一页**

v3.3 在原有 Ant Design 风格界面基础上，重点升级图片列表预览、大图查看、步骤条布局、设置区信息密度和进度反馈。

## v3.3 界面与交互亮点

- 图片列表第一列直接显示圆角缩略预览图。
- 鼠标悬停缩略图会弹出大图预览浮层。
- 悬停缩略图时显示放大镜按钮，点击进入大图查看器。
- 双击图片行也可查看大图。
- 大图查看器支持上一张、下一张、滚轮缩放、拖动画面、适应窗口和原始尺寸。
- 图片列表右键菜单支持查看大图、打开目录、上移、下移和删除。
- 步骤条文字与连接线分层显示，不再发生重叠。
- 文件数量与总体积标签加宽并补充图标，不易越界。
- 图片列表不再占用右侧固定预览栏，文件名和路径显示空间更大。
- 保存位置固定显示在操作区，默认 1200×800 窗口内常用 PPT 设置无需滚动。
- 设置区按快速预设、页面设置、图片布局分组。
- 进度条使用圆角轨道、动态高光和独立百分比胶囊。
- 卡片采用 12px 圆角，按钮、输入框和下拉框采用 8px 圆角，小图标按钮采用 6px 圆角。

## PPT → 图片

- 支持 `.ppt`、`.pptx`、`.pptm`、`.pps`、`.ppsx`
- 支持拖入多个文件或包含 PPT 的文件夹
- 支持 PNG、JPG 输出
- 支持 72～600 DPI
- 支持 JPG 质量控制
- 自动优先调用 Microsoft PowerPoint，失败后尝试 LibreOffice
- 可为每个 PPT 自动创建独立输出文件夹
- 提供“电商”“高清”“轻量”快捷预设

推荐参数：

- 1688、电商详情页、网页使用：`PNG + 200 DPI`
- 印刷、局部放大、高清存档：`PNG + 300 DPI`
- 需要减小体积：`JPG + 160～200 DPI + 90～95 质量`

## 图片 → PPT

- 支持 `.png`、`.jpg`、`.jpeg`、`.bmp`、`.tif`、`.tiff`、`.webp`
- 支持拖入多张图片或图片文件夹
- 每张图片生成一页幻灯片
- 支持拖动列表行调整页序
- 支持自然排序、批量删除和清空
- 支持 16:9、4:3、A4 横向、A4 竖向、按首图比例
- 支持完整显示或居中裁切铺满
- 默认保持图片比例，不拉伸变形

“完整显示”不会裁切或拉伸图片；“铺满页面”会保持比例并从中心裁切多余区域。

## 图片预览操作

- **悬停缩略图**：显示放大的快速预览浮层
- **点击放大镜**：打开大图查看器
- **双击图片行**：打开大图查看器
- **鼠标滚轮**：在大图查看器中放大或缩小
- **按住鼠标拖动**：移动放大后的图片
- **← / →**：切换上一张或下一张
- **Esc**：关闭大图查看器
- **Ctrl + 0**：恢复原始尺寸
- **右键图片行**：查看大图、打开目录、调整顺序或删除

## 拖拽导入

Windows 下无需安装额外拖拽组件，工具使用系统原生文件拖放能力。

- 把 PPT 文件拖入窗口，会自动加入“PPT 导出图片”任务
- 把图片拖入窗口，会自动加入“图片合成 PPT”任务
- 把文件夹拖入窗口，会识别第一层中的受支持文件
- 同时拖入 PPT 和图片时，会分别加入对应工作区
- 重复文件自动跳过

> Windows 可能限制从普通权限资源管理器向“管理员身份运行”的程序拖放。日常使用请直接双击启动，不要以管理员身份运行。

## 快速使用

### 第一次运行

1. 安装 **Python 3.10 或更高版本**，安装时勾选 `Add Python to PATH`
2. 双击 `安装依赖.bat`
3. 双击 `启动工具.bat`

### PPT 导出图片

1. 打开左侧“PPT 导出图片”
2. 拖入 PPT 文件或点击拖拽区选择
3. 选择场景预设
4. 设置输出文件夹并按需微调参数
5. 点击“开始导出图片”

### 图片合成 PPT

1. 打开左侧“图片合成 PPT”
2. 拖入图片或图片文件夹
3. 通过缩略图检查顺序，拖动列表调整页序
4. 选择页面预设、图片布局和保存位置
5. 点击“生成 PPT 文件”

## 快捷键

- `Ctrl + O`：按当前工作区添加文件
- `Delete`：删除列表中的选中项
- `Ctrl + Enter`：开始当前转换任务
- `Ctrl + ↑ / Ctrl + ↓`：在图片列表中上移或下移选中项
- 图片行双击：查看大图
- 大图查看器 `← / →`：切换图片
- 大图查看器 `Esc`：关闭
- 大图查看器 `Ctrl + 0`：原始尺寸

## 导出引擎

- **Microsoft PowerPoint**：仅 Windows，需要电脑已安装 PowerPoint，版式和字体还原通常更准确
- **LibreOffice**：免费备用方案，少数字体、特殊效果或复杂图表可能存在差异

选择“自动选择”时，会优先使用 PowerPoint；若失败，再尝试 LibreOffice。

## 打包为 EXE

完成依赖安装后，双击 `打包EXE.bat`。

生成文件：

`dist\PPT图片互转工具.exe`

图片合成 PPT 可直接使用；PPT 导出图片仍需要目标电脑安装 Microsoft PowerPoint 或 LibreOffice 之一。

## 运行自检

双击 `运行自检.bat`，或运行：

`py 自检.py`

自检会检查 Pillow、python-pptx、PyMuPDF、原生拖拽模块、应用图标和可用导出引擎。

## 常见问题

### 默认窗口仍出现设置区滚动条

1200×800 默认窗口会完整显示常用图片合成参数。窗口高度明显小于默认值时，设置区才会自动启用细滚动条；保存位置和主转换按钮始终固定可见。

### 缩略图没有显示

请确认图片文件可以正常打开，且不是仅存在于云端但尚未下载到本地。损坏或无法识别的图片仍可显示文件信息，但缩略图可能为空。

### 悬停预览遮挡内容

预览浮层会自动尝试显示在缩略图右侧；靠近屏幕边缘时会切换到左侧。移开鼠标后浮层会自动关闭，也可以直接点击放大镜进入独立查看器。

### 拖入文件没有反应

请确认：

- 当前为 Windows 系统
- 工具不是以管理员身份运行
- 文件扩展名属于支持范围
- 文件不是仅存在于云端但尚未下载到本地

仍无法拖入时，可点击拖拽区或“添加”按钮选择文件。

### 提示没有可用导出引擎

安装 Microsoft PowerPoint，或安装 LibreOffice，然后重新打开工具。

### 导出的文字或版式发生变化

优先选择 Microsoft PowerPoint 引擎，并确保本机安装了 PPT 使用的字体。

### JPG 透明区域变成白色

JPG 不支持透明通道，透明区域会自动合成到白色背景。需要透明背景时请选择 PNG。
